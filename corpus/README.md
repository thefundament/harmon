# Corpus layout

- `unreviewed/`: raw machine transcripts and metadata; **not** creator-verified, speaker-clean, permission-cleared, or training-ready.
- `discovery/`: Twitch and YouTube URL inventory with probe errors.
- `summary.json`: batch totals.

Each collection pass is bounded and keeps no raw recordings in this repository. Before republishing, redistribution or training, establish appropriate permission and review individual transcripts against the recording.
