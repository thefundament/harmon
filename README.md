# harmon — Video retrieval feasibility pilot

Small, bounded, caption-first experiment for collecting publicly accessible video speech with source provenance. It does not use credentials, cookies, bypasses, or paid services. The first workflow is limited to **one video**, **60 seconds of audio**, and **8 GitHub Actions minutes**. Output is unreviewed and is not training-cleared.

Not a mirror of the creator's videos: raw audiovisual media will not be uploaded as artifacts. The public workflow is an experiment; it might be blocked by streaming platforms.
